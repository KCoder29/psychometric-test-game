# Psychometric Test Game

## Overview

This internship project involved developing a web-based psychometric test game to explore memory and attention. Built using HTML, CSS, JavaScript, and Django, the application included picture, digit, word, and visuospatial memory tests, along with participant registration, questionnaires, consent forms, timers, and tracking of reaction time and accuracy.

The project also explored the potential relationship between sound frequency and cognitive performance, including the use of Om chanting at 432 Hz.
